# Portfolio Case Studies

A public, case-study-only collection of six customer, product, and learning projects from Rijul Raj's portfolio.

This repository contains written case-study summaries only. It intentionally excludes personal contact details, the private portfolio source, user-provided graphics, and copied game source code. The memory-game entry links to its original public project instead.

## Case Studies

| # | Case study | Summary |
| --- | --- | --- |
| 01 | [Escalation Triage Assistant](case-studies/01-escalation-triage.md) | Rule-based urgency signals and suggested first responses. |
| 02 | [Client Health-Score Tracker](case-studies/02-client-health-score.md) | A simple engagement and recency score for prioritizing follow-up. |

## Project Principles

- Start with a user or team problem and make the proposed solution inspectable.
- Keep people responsible for consequential decisions.
- Distinguish prototypes and hypotheses from measured outcomes.
- Avoid implying a demo uses live AI, production data, or integrations when it does not.

## Scope and Data

These case studies describe prototypes and concepts. The first four demos use browser-side rules and heuristics; Decision Copilot is a concept with synthetic/demo material; the memory game does not call an AI service. No customer records, credentials, private source materials, or contact details are included here.
