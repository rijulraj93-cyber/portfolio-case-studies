# 06 - GitHub Copilot Memory Game

## Purpose

The original project brief describes a memory game as a hands-on learning project for students exploring GitHub Copilot in VS Code. In that brief, `GHCP` is shorthand for GitHub Copilot; the game itself does not call an AI service.

## Experience

- 4x4 and 6x6 boards with 8 or 18 matching pairs.
- Mouse and keyboard card interaction.
- Move count, timer, rating, and a completion dialog.
- Best scores stored in the player's browser and separated by board size.
- The portfolio version also includes a user-controlled dark theme.

## Boundaries

The game is a client-side learning sample, not an AI tutor or a production learning platform. The original public source is available at [memory-game-GHCP](https://github.com/arunnandewal-happyvibes/memory-game-GHCP). This repository does not redistribute that source code.
